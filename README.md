# Banco de Dados – SQL Server

Este repositório foi criado para compartilhar minha evolução nos estudos de Banco de Dados durante o curso Técnico em Desenvolvimento de Sistemas no Senac.

Aqui vou armazenar exercícios, atividades práticas e exemplos desenvolvidos durante as aulas, utilizando SQL Server.

### 📚 Conteúdos estudados

- Criação de banco de dados (CREATE DATABASE)
- Seleção de banco de dados (USE)
- Criação de tabelas (CREATE TABLE)
- Tipos de dados
- NULL e NOT NULL
- Chave primária (PRIMARY KEY)
- Chave estrangeira (FOREIGN KEY)
- Consultas com SELECT

### 🛠️ Tecnologias e ferramentas

- SQL
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

### 🎯 Objetivo

Registrar meu aprendizado, praticar os conceitos estudados e acompanhar minha evolução na área de desenvolvimento de sistemas.
