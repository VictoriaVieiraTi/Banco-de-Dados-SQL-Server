## 📚 Conteúdos estudados

### 🗄️ Criação e estrutura do banco de dados

| Conteúdo        | Descrição                                                  |
| --------------- | ---------------------------------------------------------- |
| CREATE DATABASE | Criação de bancos de dados                                 |
| USE             | Seleção do banco de dados                                  |
| CREATE TABLE    | Criação de tabelas                                         |
| Data Types      | Tipos de dados                                             |
| IDENTITY        | Geração automática de valores numéricos                    |
| NULL e NOT NULL | Definição de campos que podem ou não receber valores nulos |

### 🔑 Chaves e relacionamentos

| Conteúdo         | Descrição                                                       |
| ---------------- | --------------------------------------------------------------- |
| PRIMARY KEY (PK) | Identificação única de cada registro                            |
| FOREIGN KEY (FK) | Criação de relacionamentos entre tabelas                        |
| Relacionamentos  | Relações 1:1, 1\:N e N\:M                                       |
| Normalização     | Organização dos dados para reduzir repetições e inconsistências |

### 🛡️ Restrições e integridade dos dados

| Conteúdo   | Descrição                                               |
| ---------- | ------------------------------------------------------- |
| CONSTRAINT | Definição de regras para manter a integridade dos dados |
| UNIQUE     | Impede valores duplicados em uma coluna                 |
| DEFAULT    | Define um valor padrão quando nenhum valor é informado  |
| CHECK      | Valida os valores de acordo com uma condição definida   |

### 🔎 Consultas e relacionamento de tabelas

| Conteúdo   | Descrição                                                               |
| ---------- | ----------------------------------------------------------------------- |
| SELECT     | Consulta e seleção de dados                                             |
| INNER JOIN | Retorna registros com correspondência nas duas tabelas                  |
| LEFT JOIN  | Retorna todos os registros da tabela à esquerda e suas correspondências |
| RIGHT JOIN | Retorna todos os registros da tabela à direita e suas correspondências  |
| FULL JOIN  | Retorna todos os registros das duas tabelas                             |
| CROSS JOIN | Gera todas as combinações possíveis entre as tabelas                    |
| SELF JOIN  | Relaciona registros de uma tabela com outros registros da mesma tabela  |

### ✏️ Manipulação e análise de dados

| Conteúdo      | Descrição                               |
| ------------- | --------------------------------------- |
| INSERT INTO   | Inserção de registros                   |
| UPDATE        | Atualização de registros existentes     |
| DELETE        | Exclusão de registros                   |
| GROUP BY      | Agrupamento de registros                |
| COUNT()       | Contagem de registros                   |
| SUM()         | Soma de valores                         |
| AVG()         | Cálculo de média                        |
| MIN() e MAX() | Identificação do menor e do maior valor |
| DROP TABLE    | Exclusão de uma tabela                  |
